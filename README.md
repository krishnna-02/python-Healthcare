# python-Healthcare
# 🏥 Healthcare Hospital Operations Data Analysis

## 📌 Project Overview
This project analyzes healthcare hospital data to uncover insights into patient admissions, treatment costs, department performance, and overall hospital operations. The analysis helps identify trends and supports data-driven decision-making for improving healthcare services.

---

## 🎯 Objectives
- Analyze patient admission trends.
- Explore department-wise performance.
- Examine treatment costs and hospital stay duration.
- Identify operational patterns through exploratory data analysis (EDA).
- Develop a Hospital Efficiency Score for performance evaluation.

---

## 📊 Dataset
The dataset contains **50,000+ healthcare records** with information such as:

- Patient ID
- Age & Gender
- Admission Date
- Department
- Diagnosis
- Treatment Cost
- Length of Stay
- Discharge Status
- Hospital Information
